# Game Design Canon

The numbered documents in this directory describe the product and game-system
intent, ordered from setup and vision through mechanics, social systems, and
events. Start with [`01-Game-Vision.md`](01-Game-Vision.md) for the product
thesis or use the main [`documentation index`](../INDEX.md) to find a current
implementation contract.

Design canon answers what the game should do. `ENGINEERING.md`, accepted ADRs,
current system docs, source code, and executable tests answer how it works now.
