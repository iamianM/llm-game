# Implementation Archive

This directory preserves how Paradise Hearts was built. It is useful for
design archaeology, rejected approaches, and the context behind later
decisions, but it is not current implementation guidance.

- `build-plans/` contains completed milestone plans.
- `phase-specs/` contains superseded browser, API, and knowledge phase specs.
- `handoffs/` contains point-in-time implementation handoffs.
- `playtests/` contains historical playtest findings.
- `build-log.md` is the chronological implementation ledger.

Paths and links inside archived documents are preserved as historical evidence
of the repository layout at that milestone; some intentionally no longer
resolve after later moves or deletions.

For current behavior, start at [`../INDEX.md`](../INDEX.md). If an archived
document conflicts with code, an accepted ADR, or a current system doc, the
current source wins.
